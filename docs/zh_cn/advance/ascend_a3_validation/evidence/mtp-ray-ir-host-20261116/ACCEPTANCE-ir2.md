- 固定原始源码5f1b1b3c、研究源码d2d933da、既有native venv/CANN/Triton与真实第0层输入fixture。旧记录不覆盖；新实验使用ir2/host2/perf2标签。native进程禁止导入/安装dlinfer。

- 真实固定输入每次恢复同一初始state；比较全部槽与已通过CPU oracle的保存结果，FP32 state atol1e-5/rtol1e-4，同时单列逐位相等和当前输出。不同生成历史不用于数值归因。

- 不改全局IRQ亲和性、系统内核参数或已有服务；亲和性避让仅是已知临时缓解，不是永久修复。脚本需保存元数据、丢事件状态，退出清理自己创建的跟踪设施。
