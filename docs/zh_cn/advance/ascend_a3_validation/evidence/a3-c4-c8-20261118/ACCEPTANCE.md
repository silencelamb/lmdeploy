# 八路并发和高差异分项独立复核

在计时前冻结样本数与判据。主比较为 A3 / TP2 / BF16 上旧 LMDeploy fb5de87a + dlinfer 3b909634 对原生 LMDeploy 2ccf38a4。原生进程和 Ray workers 使用 dlinfer 导入 guard，冻结 stack91 与 CANN 9.1.0。Agents-A1 无 MTP，Sage-A1.5 用 MTP3。两模型各自的新旧固定物理卡 8/9 与 10/11，沿用上次同卡控制。保持原部署 alignment128、prefix ON、max batch 16、session 262144、prefill 8192、128 输出 token、greedy、关闭 thinking 和实际 cache miss。

## 并发与负载

每个模型真实 HTTP C4、C8 同进程测量。每个并发每进程共 64 个测量请求，C4 分 16 批，C8 分 8 批。两份 64 条语料仅早期单数字标记不同，输入 171 token。两个并发在单个进程用不同语料以避免 prefix 命中。8 对进程按预定顺序交换语料分配，两种并发最终各跑到相同的两份语料且次数相同。新旧每对使用完全相同的输入。另保留原 C1 的 25 条请求，用于部署首 token 尾延迟。每批齐发、全部完成再进入下一批。分开记录每个请求的首 token、后续 token 时间窗、整批输出吞吐、部署 SLO 命中数，以及两 rank 的实际 target/draft prefill 和 decode 形状。批吞吐为实际输出 token 总数除以整批首尾墙钟。C8 结果另外给出 8 序列 decode forward 占比，单列 prefill 实际批大小。

每个主比较 8 对全新旧/新进程，AB、BA 各 4。HTTP 预热覆盖 C1 至 C8，至少 5 个完整 sweep，最后连续 2 个无新增观测形状、捕获、编译、autotune；最多 10 轮。测量、资格、预热使用不共享前缀块的提示，资格/测量出现冷事件单独记录失败。核对实际输出长度、finish、cache、逐条输入与输出 ID，在相同版本/并发/提示指纹的不同进程间核对重放。Sage 同时检查 draft。不同并发若引起 token 分歧，照实列出，不能据此宣称相同生成内容的加速。相同并发的版本间分歧要单列，不签等效。

## 独立确认阶段

在原设备、原配置、相同提示与相同客户端测量顺序上另跑 8 对。两个普通离线模型复用上次 pipeline 的 C1 25 次与 C4 8 批、每个进程 C1..4 至少 5 个预热 sweep。预先关注 Agents 的 C4 TTFT p50（上次 −10.31%）及吞吐/TPOT，Sage 的 C1 TTFT p95（+5.61%）和 C4 吞吐。HTTP C1 也复核上次 Sage p95 区间较宽的项目。另用物理 0/1、legacy 栈、norm 前 342db85e/后 5f1b1b3c 重放 Agents norm64 原 170→64、prefix OFF、prefill256、batch8 配置。关注 C4 吞吐（−5.35%）与 C1 TTFT p50（+6.25%）。各阶段独立报告，保留每对差值与方向数，不因中途趋势停止或追加样本。并行加载可用的不同 TP2 卡组，确认每组预热就绪之后所有正式测量窗口串行，默认 CPU 亲和性。

## 判定

每对计算 (新/旧−1)×100%，主统计取 8 对百分比的中位数；单列旧、新绝对值。沿用 10000 次配对 bootstrap 的 2.5% 和 97.5% 分位，随机种子 20261118。全部落入 ±5% 为等效。完全偏向改善且越界，列改善。区间整体落在不利的 5% 带外为确定回退，其余未定。p95 还检查按进程簇汇总后的区间。次要统计包括累计 token/累计有效秒数，和 TTFT≤3 秒且流速≥40 tok/s 的命中数。吞吐、流速越高越好，TTFT/TPOT 越低越好。等待服务、预热、写 JSON 与进程间互斥等待不计入批耗时。该固定长度单实例闭环负载用于比较，不外推满载能力或生产长前缀工作量。

## 补充真实八行 prefill

主 HTTP 工作量为 171 输入，会跨 128-token 保存边界。另在物理 12/13，用相同生产引擎配置和 99-token 自然提示做固定合批，直接在普通离线 AsyncEngine 上预处理完全部输入，再一起提交。C4 与 C8 重用完全相同的 64 个输入，均须零缓存命中。按 worker 的真实 forward 计数核对每批的 prefill 是否一次完整容纳 4 或 8 行，以及 decode 是否保持同样的活跃行数。为这个归因对照固定两对新进程 AB/BA，每侧 C4 16 批、C8 8 批，5 至 10 个 C1..8 预热 sweep。记录两个比较值和输出一致数，样本数不足以独立签 ±5% 等效。该对照的测量从全部输入已预处理后开始。其进程装载、预热、测量、退出均与主测量互斥，单列实际时间。
