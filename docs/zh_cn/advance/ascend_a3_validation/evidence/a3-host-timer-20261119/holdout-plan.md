# 独立检验的时间指纹

从以前双机 spin 和本轮 single 两组数据产生线索，不能把它们当成预测验证集。现在预先固定规则，在两个容器各再采 100 秒单线程 spin，使用相同的 fine_irq 及邻核对照，CPU84 读向量。只在同一机器上比较相邻且边界完整的事件，连续事件间距 1–4 秒，不能跳过一次实际长停顿。

预设规则：CONFIG_HZ=250，4 ms/tick，取前次用户恢复时间，折算 jiffies 时按 floor(t/4ms)+1 计，候选定时延迟 500 tick。用 Linux 5.10 INITIAL_JIFFIES=(u32)(-300*HZ) 的时钟相位，在接下来的 8 或 64 tick 桶（32/256ms）分别生成一个候选到期时刻。若真实下次起点距离两个候选中至少一个 ≤5 ms 则命中。每次给出两个时刻，不能据此断定单个具体的重置 API/参数。输出终点到下一起点的直接观测，固定起点模型的对照、打乱上一次时长的检验。若失败照报，不继续调参。
